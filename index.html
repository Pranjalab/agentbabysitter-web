What's coming next

These are being built right now. Today abs only listens while Claude Code is open on your machine — the next release changes that.

In progress

Always on, even when nothing's running

A background daemon keeps your bot awake around the clock. Message it at 2am with no terminal open and it's still there — nothing gets dropped while you're away.

In progress

Start a session from your phone

Pick a project, tap resume, and Claude Code starts on your machine — from Telegram. Messages you sent while it was idle are offered back as the opening prompt.

In progress

Sandboxed sessions

Run Claude Code inside a container with exactly one folder mounted and nothing else on your machine visible. For the work you'd rather not hand the keys to.

In progress

A restricted assistant bot

A locked-down second bot for everyday questions and notes. It can't write code, can't touch your projects, and can't start sessions — safe to hand to anyone.
